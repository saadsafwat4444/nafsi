# Nafsi 🧠💙

## 📌 Description

Nafsi is a modern web application focused on mental health awareness and support.
It provides users with helpful content, services, and resources related to psychological well-being in a clean and user-friendly interface.

---

## 🚀 Features

* 🧠 Mental health content and articles
* 📅 Appointment pages for specialists
* 👨‍⚕️ Browse services and specialists
* ❓ Interactive questions section
* 🌐 Multi-language support (Arabic / English)
* 📱 Fully responsive design

---

## 🛠️ Tech Stack

* **Framework:** Next.js
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **State Management:** React Context API

---

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/saadsafwat4444/nafsi.git
cd nafsi
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

---

## 🌍 Usage

After running the project, open:
